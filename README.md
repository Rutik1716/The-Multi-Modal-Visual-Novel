# 🎬 The Multi-Modal Visual Novel

An interactive AI-powered visual novel that combines **AI-generated storytelling, character interaction, and AI-generated visual assets**.

This project was developed as part of the **MirAI School of Technology – AI Builder Virtual Summer Internship 2026**.

The application combines **Google Gemini** for stateful story generation with **Pollinations AI** for generating visual assets based on the story.

## 🚀 Features

- 📖 AI-generated interactive story
- 🤖 Powered by Google Gemini
- 🧠 Stateful conversation and story progression
- 🎭 Character-driven interactions
- 🖼️ AI-generated visual assets
- 🎨 Uses Pollinations AI for image generation
- 💬 Interactive user choices/messages
- 🔄 Dynamic story progression
- 🌐 Built with Streamlit

## 🧠 AI Storytelling

The application uses Google Gemini to generate and continue the story based on the current conversation and user interaction.

The AI maintains the story context so that previous events can influence the continuation of the narrative.

## 🖼️ AI-Generated Visuals
